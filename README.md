# Q 아너스 (Q Honors)

비전 당구클럽에서 만난 사람들의 친목 모임 **Q 아너스** 웹사이트입니다.

- 사이트: https://q.cap89.com
- 프론트엔드: GitHub Pages (이 저장소의 `index.html` 한 파일)
- 백엔드·DB: Google Sheets + Apps Script (연결 예정)
  - Settings · Members · Meetings · RSVP · Ledger · Dues 시트
- 디자인: CAP89 스타일 + [Lucian UX/UI](https://lucianlabs.dev/uxui-prompt/) 요소 (#026 #039 #044 #059 #250, MIT © 2026 Seokwoooo)

> 현재는 **시안** 단계입니다. 데이터는 예시이며 이 브라우저에만 저장됩니다.
> `index.html`의 `CONFIG.SHEET_API`에 Apps Script 웹 앱 주소를 넣으면 시트와 연결됩니다.
